# AYLOOR — инструкция для Codex

Актуальный согласованный дизайн Street Frequency, 21.10.2026. Home и Team разделены.
Исходный commit прототипа: 201299dda422d5dd32f7930506416d5e53802fef
Демо: https://ayloor-street-frequency.ssailab-io.chatgpt.site

## Задача
Внедри этот визуальный стиль в существующий AYLOOR Telegram Mini App. Сначала прочитай AGENTS.md основного репозитория, документацию v0.1 и текущий frontend. Сохрани рабочую бизнес-логику, API, Telegram auth, проверки и обработку ошибок. Используй папку prototype как визуальный референс, а не как замену приложения. Не запускай новый проект вместо существующего.

## Согласованные экраны
- Home — стартовый экран: Yerevan Season Zero, текущее задание, Start Quest / Continue Quest, сезонный XP, место команды и прогресс. После завершения — переход к рейтингу. Для pending team — переход к сбору команды.
- Team — название, состав 2–5 человек, свободные места, приглашения, pending/active.
- Quests / Quest — First Checkpoint, briefing, старт, активное задание, check-in.
- Complete — результат +100 XP и переход в рейтинг.
- Ranks — рейтинг команд города за текущий сезон с выделением своей команды.

## Визуальный стиль
Кремовый #F3EBDD, чёрный #181816, оранжево-красный #F34B2F. Лаймовый только как небольшой индикатор active team. Barlow Condensed для заголовков; Barlow для текста. Крупная плотная типографика, прямые разделители, небольшие скругления кнопок, halftone-коллажи города. Не превращать оформление в generic SaaS или стандартный Telegram UI.
Основные исходники: prototype/src/Prototype.tsx, prototype/src/prototype.css.
Изображения: prototype/public/assets/yerevan-collage.png и cascade.png. wordmark.png — растровый концепт, не утверждённый векторный мастер логотипа.

## Что не переносить в реальное приложение
- Рамку телефона, переключатель iPhone/Pixel, нарисованные системные часы, клавиатуру и home indicator. Это инфраструктура предпросмотра; в Telegram использовать реальные safe-area/insets.
- Локальные fake-данные, имена/рейтинг демокоманд, постоянные 2/5 участников и симулированное начисление XP.
- Demo controls: simulate teammate joining, preview waiting, simulate successful check-in, outside zone, permission denied, preview creating a new team.
- Прототипный viewport scroll guard: реализовать прокрутку корректно в реальном Telegram layout.
- Инфраструктуру Sites, Worker или собственную авторизацию из демо в существующий frontend.

## Обязательные продуктовые ограничения
Команда активна с 2 участниками, максимум 5. GPS запрашивается только по нажатию Check In; никакого background tracking, live-позиции или автоматического proximity unlock. Дистанция/accuracy отображаются только при наличии действительных данных. Backend проверяет радиус и точность, начисляет XP атомарно; frontend не подтверждает completion самостоятельно. Start из Home должен использовать существующий API, включая pending/loading/error. При отсутствии команды или ранга показывать подходящее пустое состояние; не подставлять #2 из демо. Выполненное задание нельзя запустить заново.
Cascade и его карта в прототипе — иллюстрация, а не утверждённый checkpoint. Координаты/описание/ссылку карты брать из реальных данных задания; development placeholder (0,0) не показывать как реальную точку. Не добавлять новые игровые механики, магазин, награды, live tracking или глобальный рейтинг. Не менять backend ради визуального совпадения.

## Порядок работы
1. Изучи текущий Mini App и сопоставь существующие состояния с референсом.
2. Выдели дизайн-токены и переиспользуемые компоненты.
3. Перенеси Home и Team раздельно; затем Quest, Complete, Ranks и состояния ошибок.
4. Подключи существующие данные/API, убрав симуляцию.
5. Проверь основной сценарий, небольшие экраны, Telegram safe areas, loading/error/pending/completed, отсутствие повторного XP. Используй существующие проверки проекта; проверь mobile overflow и читаемость.
6. Покажи изменения и перечисли то, что ещё осталось демонстрационным.

Это согласованное визуальное направление, не production-ready Telegram клиент. Проверка точного визуального совпадения 1:1 в предыдущей среде осталась ограниченной; перед релизом проверь на реальном устройстве.
