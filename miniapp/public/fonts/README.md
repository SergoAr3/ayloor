# Production fonts

Self-hosted Latin WOFF2 subsets from Fontsource (no npm runtime dependency):

- Barlow 5.3.0: https://registry.npmjs.org/@fontsource/barlow/-/barlow-5.3.0.tgz
  Body weights: 400, 500, 600. License: `barlow-LICENSE.txt`.
- Barlow Condensed 5.3.0: https://registry.npmjs.org/@fontsource/barlow-condensed/-/barlow-condensed-5.3.0.tgz
  Display weights: 600, 700, 800. License: `barlow-condensed-LICENSE.txt`.

Both font families use the SIL Open Font License 1.1. The license texts are copied
from the packages. Other scripts in player/team names use the CSS system fallback.
